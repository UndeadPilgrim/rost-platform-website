- **Architecture:** Pure static Next.js frontend; no API routes, DB, or env usage.
- **Dev-environment gotchas (2026-09-04):** (1) Next 16 blocks 127.0.0.1 in dev — always use http://localhost:3000. (2) Next 16 dev image cache lives at .next/dev/cache/images and does NOT invalidate when a public asset file is replaced — clear it (or rm -rf .next with the server stopped) after swapping assets, else Chromium may serve stale-variant decodes. (3) Running `bun run build` replaces .next while a dev server holds its route manifests in memory → dev then 404s every route; restart dev (or rm -rf .next + restart) after a build. (4) Symptom "hero animates but scroll reveals/stage activation dead" = stale server/tab state, not code; recovery is stop server, rm -rf .next, bun run dev, hard-refresh.
